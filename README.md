# 영상 편집 포트폴리오

전체 작업 중 일부인 YouTube 영상 17편을 8개 분야로 정리한 반응형 포트폴리오입니다.

- 분야 필터: 토크, 브이로그, 다큐, 부동산, 게임, 버츄얼, 병원, 쇼츠
- 쇼츠는 세로형 썸네일과 플레이어로 표시합니다.
- 영상을 누르면 플레이어가 열리며, YouTube 원본으로 이동할 수도 있습니다.
- 별도 설치나 빌드 없이 GitHub Pages에서 실행합니다.
- 영상 제목과 채널명은 YouTube oEmbed에서 확인한 정보입니다.

영상 추가·수정 시 `index.html`의 작업물 카드와 필터별 편수를 함께 수정하세요. `videos.json`에는 원본 영상 목록이 들어 있습니다.

영상과 썸네일의 권리는 각 원본 권리자에게 있습니다.
